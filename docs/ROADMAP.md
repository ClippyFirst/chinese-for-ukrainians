# Chinese for Ukrainians — Roadmap

## Phase 0 — Foundation
- document product requirements;
- document architecture;
- document visual system;
- validate the current transcription CSV;
- decide pronunciation engine and licensing;
- establish tests.

## Phase 1 — MVP
- static page;
- Chinese input;
- Auto/Simplified/Traditional selector;
- Pinyin;
- Kirnosova;
- Kirnosova–Tsisar;
- NANU;
- copy controls;
- responsive/accessibility baseline.

## Phase 2 — Reliability
- broader polyphonic word resolution;
- unresolved/ambiguous pronunciation UI;
- richer regression corpus;
- generated data validation.

## Phase 3 — Comparison tooling
- synchronized highlighting by syllable;
- click a syllable to see Pinyin and all three Ukrainian outputs;
- side-by-side difference emphasis;
- source row/rule explanation.

## Phase 4 — Optional expansion
Only if there is a clear need:
- Cantonese/Jyutping;
- additional Ukrainian transcription systems;
- Belarusian system;
- Russian Palladius;
- Wade–Giles;
- Zhuyin.

These should be separate modules built on the same canonical pronunciation architecture.
