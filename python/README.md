# zhua — Chinese to Ukrainian transcription

Alpha Python library and CLI for offline batch processing. The browser app remains the public web interface; this package is not yet published to PyPI.

Install from the repository: `python -m pip install ./python`.

```python
import zhua
result = zhua.convert("你好世界")
print(result.pinyin, result.ipa, result.kirnosova)
print(result.as_dict())  # tokens, spans and mapping issue states
zhua.transcribe("你好", "nanu")
zhua.transcribe_all("你好")
```

CLI: `chuktrans "你好"`, `printf '你好' | chuktrans --json`, or `chuktrans --system kirnosova "你好"`.

System identifiers: `kirnosova`, `kirnosova_tsisar`, `nanu`. Python uses pypinyin 0.55.0; the website uses pinyin-pro. These engines can differ on polyphonic words, names and segmentation. The shared fixture establishes exact parity only for its listed cases. IPA is broad and uses lexical citation tones; no tone sandhi or acoustic narrow transcription is claimed. Blank mappings and unsupported IPA remain unresolved; no Pinyin fallback exists.

The root `zh-in-ua.csv` is canonical. The package-data copy is generated by `npm run generate:data`; do not edit it manually.
